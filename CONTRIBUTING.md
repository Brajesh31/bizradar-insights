# Contributing

Use synthetic market, location, competitor, and account data in development.

1. Create a focused branch.
2. Copy `.env.example` to an untracked local environment and configure a development Supabase project.
3. Run `npm ci`, `npm run lint`, and `npm run build`.
4. Test authentication, protected flows, analysis panels, map behavior, and responsive layout.
5. Update Supabase migrations and technical documentation with schema or function changes.

Pull requests should describe affected routes, data contracts, migrations, verification commands, and privacy implications. Report vulnerabilities privately through [SECURITY.md](SECURITY.md).
