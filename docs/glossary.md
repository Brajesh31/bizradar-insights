# 📖 Glossary

| Term | Meaning |
|---|---|
| BizScore | Composite heuristic opportunity score |
| Demand Index | Modeled demand-strength indicator |
| Competition Index | Modeled competitive pressure |
| Competition Density | Categorical competition classification |
| Category Intelligence | Rules/metadata associated with a business category |
| Feasibility Report | Structured analysis for a candidate business/location |
| Opportunity Card | UI summary of a generated business concept |
| Saved Idea | User-owned stored candidate/analysis |
| Custom Idea | User-submitted business idea |
| SWOT | Strengths, Weaknesses, Opportunities, Threats |
| RLS | PostgreSQL Row-Level Security |
| Supabase Auth | Hosted identity/session service |
| Edge Function | Deno server-side function deployed on Supabase |
| Publishable Key | Browser-safe Supabase project key |
| Service-role Key | Privileged server credential; never expose to browser |
| Vite | Frontend development/build tool |
| SPA | Single-page application |
| Synthetic Data | Generated illustrative values, not measured observations |
| Rule-based Model | Fixed formula/logic, not trained ML |
| AI-generated | Content produced by an external model |
| Data Provenance | Origin, time, method and quality of a value |
| Forecast Horizon | Future time window projected |
| Methodology Version | Identifier for scoring formula/rules |
| Idempotency | Repeated request does not duplicate its effect |
